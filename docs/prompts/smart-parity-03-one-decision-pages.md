# Prompt 03 — One-Decision Page Pattern

Apply the shared SMART page pattern to pages that still feel dense.

## Requirements

- Each page must show source/status, the next step, one primary action, Help, and More before secondary tools.
- Dashboard must answer what to fix first.
- Campus/Rooms must lead with room readiness before map editing.
- Schedules/Publish must expose the schedule selector before mode clutter.
- Setup pages must keep content visible early.
- Faculty/Public pages must remain mobile-first.

## Gate

- Every audited page answers “What should I do next?” in the first viewport.
