## 6. Operational facts — verified traps on this host

- **`cli.mjs status` reports `"live": false` structurally** (`supervisor.mjs:401` reads an in-process map populated
  only in the spawning process). **Never read a deploy failure out of it.** The state file's
  `state`/`ownedPids`/`releaseSha` **must still be trusted**, and only the one inside the **active**
  `ATLAS_RUNTIME_SOURCE_DIR` is authoritative.
- **End the scheduled task first** — on two prior A2 cutovers that alone quiesced the whole tree, no manual kill
  needed. An out-of-process `cli.mjs stop` does **not** quiesce the resident supervisor.
- **§6's task-XML steps require an ELEVATED shell.** `schtasks /query /xml`, `/change /tr` and re-registration all
  return *Access is denied* unelevated, because the task runs as SYSTEM. The pre-action reviewer could not verify
  these read-only for exactly that reason and marked them unperformed. **Verify `IsInRole(Administrator)` before
  step 1 and report honestly if a write did not take** — the method is elevation-requiring, not unsatisfiable, and it
  is verified here at execution rather than assumed.
- **`schtasks /change /tr` FAILS on a path containing spaces.** Use the XML route: export, replace the release path
  in **both** `<Arguments>` and `<WorkingDirectory>`, re-register. The raw `schtasks /query /xml` output on this host
  is **ASCII bytes declaring `encoding="UTF-16"`** (measured: 1467 bytes, first four `3C 3F 78 6D`) and registers
  cleanly unmodified — **do not rewrite the declaration.** Capture it with `cmd /c` redirection; PowerShell's `>`
  re-encodes it and breaks it.
- `EADDRINUSE` on 5001 during cutover is **expected**, not a defect.
- Pass explicit `ATLAS_RUNTIME_SOURCE_DIR`/`ATLAS_RUNTIME_RELEASE_SHA` into every `cli.mjs` call. **Read identity from
  machine scope + the task action + the listeners, never from `Env:`.**
- `VITE_ENROLLPRO_URL` **must** be exported for the client build; the fail-closed guard emits no bundle without it.
- `prisma generate` from `atlas-server` with `--schema` at the **repo-root** `prisma/schema.prisma`.
- **§2 corruption:** never `Get-Content | Set-Content` a repository file — it destroyed em-dashes and added a BOM
  in this very session. Write files with an explicit UTF-8 encoder and **no BOM**, and verify with a byte census.
