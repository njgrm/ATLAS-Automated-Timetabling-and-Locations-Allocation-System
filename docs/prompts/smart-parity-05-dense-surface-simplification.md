# Prompt 05 — Dense Surface Simplification

Clean up remaining cockpit-style surfaces while preserving existing capabilities.

## Requirements

- Convert mobile tables into cards/lists where scanning a table is impractical.
- Keep rows to one primary action plus More.
- Move long explanations into details sheets.
- Hide advanced controls behind More, Advanced, or Details.
- Keep every action label plain and role-appropriate.

## Gate

- No page exposes multiple competing primary workflows on first load.
