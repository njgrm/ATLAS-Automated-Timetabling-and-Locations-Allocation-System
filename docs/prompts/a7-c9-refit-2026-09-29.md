## Root cause 1 (the whole population) — `tailwind-merge` deletes the fix

`cn()` runs `twMerge`. In Tailwind v4 a `text-*` size utility emits **both** `font-size` and `line-height`, so
twMerge treats `text-xs` as conflicting with the `leading-*` group. Any `<Badge>` consumer that re-states a
font size therefore **silently removes the base `leading-none`**, putting the 20px line box back inside an 18px
content box:

```
ui/badge-variants.ts base :  ... text-xs font-medium leading-none whitespace-nowrap ...
AppSidebar.tsx:283 consumer: className='mt-0.5 min-h-5 w-fit border-purple-200 bg-purple-50 px-1 text-xs font-bold ...'
                                  ^^^^^^^^^^^ twMerge drops the later base `leading-none`
rendered: lh 20px, clientHeight 18, scrollHeight 21   -> clipped
```

Same mechanism on the Map `Ready` chips (`RoomReadinessList.tsx`), `View only`, and the `Admin` chip on every page.

## Root cause 2 — a `py-*` override on a fixed-height box

`Dashboard.tsx:604` and `:642` pass `px-2.5 py-1.5` to a `h-5` (20px) Badge. 20 − 2 (border) − 12 (padding) = a
6px content box, so even a correct 14px line box is cut. The house-correct idiom is already on the same page at
`Dashboard.tsx:586`: `h-7` with `px-2.5` and **no** `py` override.

## What to change

1. **Make the primitive's line box untwMergeable** (one change, fixes ~117 of 119 chips). `leading-none` cannot
   stay the mechanism. Give `badgeVariants()` a line-height declaration that a consumer's `text-*` cannot win —
   a Tailwind v4 `@utility`/class of its own in `index.css` is the expected shape, since twMerge does not know
   unknown class names. Keep the pill **20px tall**; do not grow it. Keep `leading-none` too if you like, but the
   proof is that the rendered line box stays 14px when the consumer re-states `text-xs`.
2. **Give every `py-*`-on-fixed-height pill the room it asks for**, or drop the `py`. Fixed box + vertical padding
   must add up (h-5 pairs with `py-0.5`; `py-1.5` needs `h-7`). Sweep **statically** for `<Badge … py-…>` across
   `atlas-client/src` and report the count you fixed vs. the count you judged already-correct — a hidden or
   collapsed view will not show up in the rendered walk.
3. **A gate that discriminates.** Extend `a7-c8-type-scale.test.ts` or add `a7-c9-refit.test.ts`, wired into
   `test:client-suite` **in the same commit**. It must fail on today's base and pass after the fix: assert that
   `cn(badgeVariants(), 'text-xs')` (and `'text-sm'`) still resolves to a 1-line-height line box — i.e. the real
   merge, not a string match. Prove it fails first on the base commit and record the literal command and output.
4. **Do not** add `truncate`, `text-overflow`, `line-clamp`, or any new ellipsis. **Do not** raise a pill's
   height where it breaks the row rhythm — give the row room instead. **Do not** edit a test to make a gate pass.
