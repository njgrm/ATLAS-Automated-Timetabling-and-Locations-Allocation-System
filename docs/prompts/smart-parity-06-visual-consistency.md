# Prompt 06 — Visual Consistency Pass

Normalize ATLAS visual language across pages.

## Requirements

- Standardize spacing, border radius, shadows, button hierarchy, badges, icon usage, skeletons, empty states, error states, and sheet/drawer footers.
- Add or reuse shared components for SMART page frame, command bar, source status, next step, help, empty state, and error state.
- Avoid one-off visual styles unless required by domain meaning.

## Gate

- Similar page elements look and behave the same across the app.
