# Prompt 3 — Setup QoL and Progressive Disclosure

## Objective

Reduce repetitive setup work across Subjects, Sections, Teachers, and Campus Map while retaining school-year and source-of-truth safeguards.

## Tasks

1. Subjects: keep the default list minimal; move coverage, room constraints, and rotation evidence to the review sheet. Add saved quick views for missing coverage and room-constrained subjects.
2. Sections: remove dead legacy filter-wall markup; add quick views for Needs room, Over capacity, and Offline changes. Preview bulk home-room operations before apply.
3. Teachers: add saved quick views for Needs teaching load, Over weekly limit, and Placeholder teachers. Persist the last safe local filter selection per user/school year.
4. Campus Map: add Saved/Saving/Unsaved/Failed state, Undo for reversible local edits, and keep geometry under Advanced placement.
5. Standardize filter counts, clear-all behavior, keyboard access, and mobile cards.
6. Extract route-local components before any file reaches 1,000 lines.

## Exit Gate

GO when the most common setup exceptions are reachable in one interaction, bulk changes require preview, and page-level overflow/file-size gates pass.
