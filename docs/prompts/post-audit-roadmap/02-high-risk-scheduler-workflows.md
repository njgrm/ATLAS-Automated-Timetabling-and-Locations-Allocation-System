# Prompt 2 — High-Risk Scheduler Workflows

## Objective

Reduce error risk and cognitive load on Teaching Load, Timetable, Room Schedules, and Audit without weakening validation or expert capability.

## Tasks

1. Teaching Load: add a task-first guided entry that frames the selected teacher/class, top issue, recommended next action, and saved state. Keep integrity/reconciliation tools under an explicit Expert Tools disclosure.
2. Timetable: preserve the three-panel workspace and selected-run truth; add a beginner-safe Review mode driven by the ranked action queue. Keep drag alternatives and preview/confirm/result semantics.
3. Room Schedules: default to search-first selection; keep rooms/teachers/sections and Run ID troubleshooting under progressive disclosure. Use mobile day cards rather than a compressed desktop grid.
4. Audit: default to the five highest-impact “Fix these first” findings; keep raw codes/source evidence behind disclosure and allow a finding-level recheck.
5. Replace remaining user-facing hard/soft/run/generation jargon where plain language is sufficient.
6. Add tests for ranking, default mode, and advanced-control disclosure.

## Exit Gate

GO when representative scheduler journeys can identify a next action within five seconds, preview every schedule-changing action, and complete without drag-only or code-only interaction.
