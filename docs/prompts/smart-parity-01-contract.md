# Prompt 01 — SMART Parity Contract

Create or update the project-local SMART-family UX contract for ATLAS.

## Requirements

- Define shared page anatomy: compact command bar, source/status chip, one visible primary action, Help, More, local scroll region, and progressive disclosure.
- Lock visual standards for typography, spacing, badges, cards, drawers/sheets, loading, empty, error, disabled, and mobile card/list states.
- Align the contract with `docs/DESIGN.md`, `docs/DESIGN-INSPIRATION.md`, `.github/instructions/frontend.instructions.md`, and ATLAS SMART-family rules.
- State that SMART parity means shared product-family rhythm, not copying SMART grading domain behavior or hard-coded SMART colors.

## Gate

- The contract can be used as a checklist for every route.
- The contract preserves EnrollPro/HNHS token-driven branding.
