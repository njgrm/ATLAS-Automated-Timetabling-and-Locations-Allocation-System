# Prompt 04 — Universal Help and Guidance

Generalize the Timetable help model across ATLAS.

## Requirements

- Add or standardize a manual `How to use this page` trigger.
- Use short visual help steps, not paragraphs.
- Use Radix Dialog/Popover/DropdownMenu focus behavior so Escape closes overlays and focus returns to the trigger.
- Add plain-language status keys and disabled-action reasons.
- Add aria-live updates for save, sync, retry, and failure states where dynamic actions occur.

## Gate

- Older non-technical users can understand each page’s primary action without external explanation.
