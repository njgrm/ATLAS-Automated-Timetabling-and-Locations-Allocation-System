# Prompt 02 — Cross-Page SMART Audit

Add and run a browser-backed SMART parity audit across Dashboard, Sections, Subjects, Teachers, Teaching Load, Timetable, Campus/Rooms, Schedules/Publish, Faculty dashboard/schedule, and Public/student schedule pages.

## Requirements

- Measure no global scrollbars, no horizontal overflow, no text overlap, first useful content, source-truth visibility, primary action visibility, and Help availability.
- Capture desktop, mobile portrait, and mobile landscape evidence.
- Produce a GO/NO-GO report per page with exact blockers.

## Gate

- Audit report exists with route, viewport, result, and blocker notes.
