## The two design rulings, so you can overrule them

**1. "Class Schedule" wins the naming — the nav was not renamed to "Timetable."** I enumerated the surface first:
"Class Schedule" is *already* the nav item, the group divider, the breadcrumb group, **the page `<h1>`** and the
product's own cross-page links ("Open Class Schedule"). "Timetable" was the internal name leaking out. So the
fix closes the leak rather than renaming five committed surfaces and breaking ~10 test contracts to swap a
familiar everyday word for a less familiar one.

**2. `schedule`, not `Class Schedule`, for a person's or a revision's own weekly schedule.** The executor caught
that my own packet contradicted itself here (§2a listed the Undo control and the revision badge, while §2b
protects the same noun in the dock). It resolved it the only consistent way, and I am recording it as a
**packet correction**, not a deviation.

## The defect that mattered most, and it was not mine to see

**QA round 1 found a BLOCKING defect that every gate in this range passed: a 36-line code comment rendering as
2,270 characters of literal text inside the Publish control, on every state.** A2's correction had wrapped the
return in a fragment, which moved a bare `/* … */` **inside the JSX children list — where a block comment is
text, not a comment.** QA proved it differentially: base 28 characters of visible text, candidate 2,270,
containing `A2-C6-TRUTH` and `AGENTS.md` references. **My four loopback captures could not have caught it**,
because they show the loading skeleton, which renders no lifecycle control.

It is fixed by hoisting the note above the `return` — text unchanged and still required (§16), **only its
position moved**, with a new dated note naming the general rule: *a comment in JSX children is a string a
scheduler reads.* Round 2 closed the class, not just the instance, with a TypeScript-AST scan of all 20 changed
`.tsx` files on three trees, and re-derived F1 as a **render** rather than a diff read — a control that fails on
the pre-fix commit and passes on the candidate.
